# Plugin migration audit

Core keeps the trusted pieces: the HA token store and link, the weather source, screensaver and the Plex account. Live TV Tuner, Guide data, BLE proxy, TV sensors, Cameras and the Denon receiver are first-party plugins of the helper (FIRST_PARTY_IDS in local.rs), off until switched on in Settings. Packaged plugins (home-assistant) go through the broker (plugins/ in the helper); Home Assistant also has a switch of its own (`ha_plugin.rs`), off until switched on in Settings, without which its packaged program is not run. Permissions limit what each can reach: ha.call domains, camera.provider (level 2), lease:decoder (level 2), net.listen brokered, net.lan for LAN devices. The TV speaks plugin level 1 (`session::TV_LEVEL`); a manifest whose `api.min` is 2 is refused. Denon needs a new permission before it can move.

Verified plugin API facts: camera.provider is level 2 (needs cameras:1); lease:esphome is level 1 (esphome.attach); lease:decoder is level 2; net.listen:6053 is brokered via net.listening (Wi-Fi address and mac). ha.call allowed: light, scene, switch, cover, climate, fan, media_player, lock, alarm_control_panel, siren. Refused: script, automation, homeassistant, mqtt. Classes S/M/L (RAM 8/24/64 MiB).

Order (lowest risk and highest value first; TV works at each step):
1. Plex photos: closed 2026-11-06, nothing on the TV to move (row above).
2. Scrypted cameras: done 2026-11-06, first-party `scrypted-cameras` with Ring inside it (rows above).
3. Home Assistant: done 2026-11-06, plugin `home-assistant` (rows above). The token store and link stay in core for voice and the ESPHome device, whose BLE proxy and TV sensors keep their own switches. Lamp control stays off until tested.
4. Screensaver complications: done 2026-11-06, the saver stays core and its integration sources follow their plugins (row above).
5. BLE proxy: done 2026-11-06, `ble-proxy` is off on a fresh install; switched off with the TV sensors off, port 6053 closes, the mDNS announcement is withdrawn and the scan ends. With the TV sensors on the device keeps its port and announcement for them, and only the radio is handed back.
6. Denon: done 2026-11-06, first-party `denon-receiver` in the helper (row above); `base.receiver` and its `enabled` switch are gone.
7. Marquee: out of scope.

The status-bar camera button is an item of the shipped layout's status bar (`payload/theme/layout.json`); it is hidden while the plugin is off. No secret values were read.

Live-state risks on Nitin's TV: HA tokens (ha/link.json, voice/ha.json); the Scrypted link and camera choices (scrypted/link.json, settings/scrypted-cameras.json); base.livetv settings; paneldim.json must be restored on every exit; direct boot (LG Home removal) means no core piece may depend on LG Home.
