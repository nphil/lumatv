LumaTV system screens

Mockups of LumaTV’s own Settings, windows, AI-access controls and the rest of the shell (quick panel, OSDs, library, drawers, prompts, screensaver, boot) for the LG C4, drawn in Lucent (TV profile, Rosé Pine) to sit beside the current LumaHome and LumaShow’s Settings. 1920×1080, Manrope, remote-first with a hover state for the Magic Remote pointer. Open live shows the real HTML: arrow keys move focus, OK (Enter) toggles. Mapping of LG’s items to the curated sections: settings-map.md
