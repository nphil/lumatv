# Avatars

The pictures in this folder are the bundled avatar gallery of LumaTV's profiles. Both sets are CC0 1.0 (public domain
dedication, https://creativecommons.org/publicdomain/zero/1.0/); nothing is required, and the artists are named anyway.

- **People** (`people-NN.png`): DiceBear Lorelei, a remix of Lorelei by Lisa Wischofsky (https://www.dicebear.com/styles/lorelei/). Licence: CC0 1.0.
- **Critters** (`critters-NN.png`): DiceBear Critters, by DiceBear (https://www.dicebear.com/styles/critters/). Licence: CC0 1.0.

Made by `tools/gen_avatars.py` from DiceBear's API (10.x) on the profile colours; the DiceBear code is MIT licensed, each style's art has its
own licence (https://www.dicebear.com/licenses/). A person's own photo is not in this folder: it is kept with the profile.
